# Udesk

> Udesk (Beijing Wofeng Times Data Technology Co., Ltd. / 沃丰科技) is a Chinese
> intelligent customer-service and CX platform: omnichannel in-app/web IM,
> ticketing, cloud call center (CC PaaS), AI chat/voice robots (GaussMind),
> field service (ServiceGo), knowledge management (KCS), and video customer
> service. Developer center: https://www.udesk.cn/doc/ — REST-style Open APIs
> (v2 recommended, v1 legacy), event-callback webhooks, and mobile/web SDKs.
> All APIs are tenant-scoped ([subdomain].udesk.cn) and authenticate with
> signed requests (SHA-256/SHA-1 signatures over admin email + API token +
> timestamp + nonce). Default rate limit: 60 requests/minute.

This file was generated by API Evangelist from https://www.udesk.cn/doc/ on
2026-07-21 (the provider does not publish its own llms.txt; /llms.txt returns 404).
